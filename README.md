## ✨ About

This is my personal developer portfolio — a place where I showcase my projects, technical skills, experience, certificates, and the technologies I work with.

The portfolio is designed to be more than a traditional single-page website. It uses a component-based React architecture and separate routes for different sections of the portfolio, creating a cleaner and more interactive browsing experience.

The project is continuously evolving as I improve my development skills and build new products.

## 🏗️ Project Architecture

The portfolio follows a modular React structure designed to keep pages and reusable UI components separated.

```text
portfolio/
├── public/
│
├── src/
│   ├── components/
│   │   ├── about/
│   │   ├── certificates/
│   │   ├── contact/
│   │   ├── experience/
│   │   ├── footer/
│   │   ├── hero/
│   │   ├── navbar/
│   │   ├── projects/
│   │   └── skills/
│   │
│   ├── pages/
│   │   ├── HomePage.jsx
│   │   ├── AboutPage.jsx
│   │   ├── SkillsPage.jsx
```

## 📦 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js 18+
* npm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/TemurbekCode/portfolio.git
```

Move into the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal, usually:

```text
http://localhost:5173
```

---

## 🔨 Build for Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The production files will be generated inside:

```text
dist/
```

## 🧭 Portfolio Routes

The application uses React Router to provide separate pages for different parts of the portfolio.

| Route           | Description       |
| --------------- | ----------------- |
| `/`             | Home              |
| `/about`        | About me          |
| `/skills`       | Technical skills  |
| `/projects`     | Featured projects |
| `/experience`   | Experience        |
| `/certificates` | Certificates      |
| `/contact`      | Contact           |

This structure keeps the portfolio from becoming a single large scrolling page and allows each major section to have its own route.

---

## 🎨 Design Philosophy

The goal of this portfolio is to avoid the typical:

```text
Hero
↓
About
↓
Skills
↓
Projects
↓
Contact
```

single-page template approach.

Instead, the project is being developed as an interactive digital experience with:

* Full-page views
* Route-based navigation
* Smooth transitions
* Strong visual hierarchy
* Minimal and modern UI
* Interactive project presentation
* Responsive layouts
* Reusable React components

The design and interaction system are continuously being refined.
